## Build with protocol SDKs

Plug and play kits from ecosystem protocols. They work with the tools you use.

- [Aave v3 React kit](https://aave.com/docs/aave-v3/getting-started/react): Hooks and components for building on Aave v3.
- [Morpho SDKs](https://docs.morpho.org/developers/sdks/get-started/): TypeScript SDKs for vaults and markets.
- [Euler SDK](https://docs.euler.finance/developers/sdk): Programmatic access to EVK vaults and swaps.
- [Curvance SDK](https://docs.curvance.com/app/developer-docs/sdk): Developer SDK for the Curvance protocol.
- [Perpl SDK](https://docs.perpl.xyz/resources/for-developers/sdk): Build on the Perpl perpetuals engine.
- [Smart Wallets SDK](https://www.alchemy.com/docs/wallets/quickstart): Wallet APIs with bundler, gas sponsorship, and ERC-20 gas payments on Monad mainnet.
- [Alchemy CLI](https://www.alchemy.com/docs/alchemy-cli): One binary for RPC, wallets, and webhooks. Agent-ready with --json.
- [Blend SDKs](https://docs.blend.money/build/sdk/overview): Frontend and server TypeScript SDKs for deposits, withdrawals, and yield accounts.
- [Zerion CLI](https://developers.zerion.io/build-with-ai/zerion-cli): Analyze wallets, sign, swap, and send on Monad from the command line. JSON output, agent-ready.

## MCP servers and skills

Connect an agent to Monad and the ecosystem. Model Context Protocol servers and agent skills.

### Alchemy

- [Alchemy MCP Server](https://www.alchemy.com/docs/alchemy-mcp-server): Hosted MCP server. Live chain data as tool calls, no API key required.
- [Alchemy Agent Skills](https://www.alchemy.com/docs/alchemy-agent-skills): Teach a coding agent every Alchemy API with one install.
- [Alchemy agent auth and payment](https://www.alchemy.com/docs/alchemy-for-agents): Wallet-based auth for agents. Pay for compute in USDC via x402.

### Envio

- [Envio indexer skills](https://docs.envio.dev/blog/ai-agents-acting-onchain-indexer): HyperIndex ships 14 agent skills. Prompt-to-production indexers on Monad.

### Uniswap

- [Uniswap AI Skills](https://developers.uniswap.org/docs/uniswap-ai/skills): Agent skills for trading and liquidity on Uniswap.

### Morpho

- [Morpho Agents](https://docs.morpho.org/developers/agents/get-started/): Agent toolkit for automated onchain strategies.

### Zerion

- [Zerion Agent Skills](https://developers.zerion.io/build-with-ai/zerion-cli#skills): Six skills for wallet analysis, trading, and signing on Monad. Installs into any coding agent.

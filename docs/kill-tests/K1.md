# K1: historical `debug_traceCall` + read-only slots in `prestateTracer`

Run: 2026-10-07 (IST), `scripts/k1-probe.ts`, real Monad RPCs only. Raw data: `results/k1.json` (summary), `results/k1-raw-*.json` (raw responses), `results/k1-partial/*.json` (per endpoint).
No Alchemy / QuickNode / Dwellir key exists in `.env` (only `HOTSLOT_NETWORK`, `HOTSLOT_PRIVATE_KEY`), so no paid provider was probed. The script picks up `ALCHEMY_API_KEY`, `QUICKNODE_URL`, `DWELLIR_API_KEY` automatically if they are added.

## Verdict: PASS (with three caveats that change the design)

| K1 clause | Result |
|---|---|
| `debug_traceCall` accepts a historical block **number** | PASS on every endpoint that allows `debug_traceCall`, within that endpoint's state window |
| `debug_traceCall` accepts a block **hash** | PASS: bare hash string, `{"blockHash":"0x.."}` and `{"blockNumber":"0x.."}` all work |
| `prestateTracer` lists read-only slots | PASS **only in non-diff mode**. `diffMode:true` omits them (it lists changed slots only) |

Caveats:

1. **Dependency set = non-diff `prestateTracer` `pre`, not `diffMode`.** Verified with `WMON.balanceOf(holder)` (a pure read) on mainnet (3 endpoints) and testnet (2 endpoints): non-diff lists the holder's balance slot under `<token>.storage`; `diffMode:true` returns no storage at all for the same call. For a `transfer`, non-diff and diffMode both list the 2 touched slots, with post values only in diffMode.
   The PRD wording "prestateTracer at latest" is right, as long as `diffMode` is false/absent.
2. **Block overrides are NOT supported.** See "Overrides". The PRD's +1 block time-dependence re-sim cannot use `blockOverrides` on the RPC; it needs the local-fork path (not tested here).
3. **Free public endpoints differ hugely on history.** Only `rpc2.monad.xyz` (Goldsky) and `rpc-mainnet.monadinfra.com` are full archive AND allow debug tracing on mainnet. `rpc.monad.xyz` keeps about 1.5M blocks (about 7 days).

The PRD fallback ("backtest on a local fork at archive state; if read-only slots are missing, say written slots only") is **not triggered**. A hosted archive with tracing exists for free (rate-limited).

## Exact request shapes that work

Same on every endpoint that allows the method (mainnet and testnet). Values are from real calls; `WMON = 0x3bd359C1119dA7Da1D913D1C4D2B7c461115433A` (mainnet canonical, from docs.monad.xyz network-information).

Pure read, historical block by number, non-diff prestate (this is the dependency-set call):
```json
{"jsonrpc":"2.0","id":1,"method":"debug_traceCall","params":[
  {"from":"0xd5b70d70cbe6c42bcd1aaa662a21673a83f4615b","to":"0x3bd359C1119dA7Da1D913D1C4D2B7c461115433A","data":"0x70a08231000000000000000000000000d5b70d70cbe6c42bcd1aaa662a21673a83f4615b"},
  "0x6a10fb0",
  {"tracer":"prestateTracer"}
]}
```
Block by hash (three equivalent spellings, all OK):
```json
"0xe9150a02734e44633d115ee8a38a46674d5d03147a5c2b7be18fbbcea9bd61b2"
{"blockHash":"0xe9150a02734e44633d115ee8a38a46674d5d03147a5c2b7be18fbbcea9bd61b2"}
{"blockNumber":"0x6a10fb4"}
```
Tracer options (`{"tracer":"prestateTracer"}` and `{"tracer":"prestateTracer","tracerConfig":{"diffMode":false}}` behave identically; `callTracer` also works):
```json
{"tracer":"prestateTracer","tracerConfig":{"diffMode":true}}
```
Result of non-diff on a pure read (shape): `{ "<addr>": { "balance", "nonce", "code", "storage": { "<slot>": "<value>" } } }`. Result of `diffMode:true`: `{ "pre": {...}, "post": {...} }`, changed fields only, no storage for a pure read.

State override (works in both `eth_call` as 3rd param and `debug_traceCall` inside the options object; verified by `Multicall3.getEthBalance` returning the overridden 1e18):
```json
{"method":"eth_call","params":[{"to":"0xcA11bde05977b3631167028862bE2a173976CA11","data":"0x4d2301cc<addr32>"},"latest",{"0x00000000000000000000000000000000000000AA":{"balance":"0xde0b6b3a7640000"}}]}
{"method":"debug_traceCall","params":[{...},"latest",{"tracer":"callTracer","stateOverrides":{"0x...AA":{"balance":"0xde0b6b3a7640000"}}}]}
```
Block traces:
```json
{"method":"debug_traceBlockByNumber","params":["0x6a10fb4",{"tracer":"prestateTracer","tracerConfig":{"diffMode":true}}]}
{"method":"debug_traceBlockByHash","params":["0xe104...","{same options}"]}
```

## Overrides (matters for the time-dependence re-sim)

| Feature | Result (all debug-enabled mainnet + testnet endpoints) |
|---|---|
| `eth_call` state override (3rd param) | Works |
| `debug_traceCall` `stateOverrides` in options | Works |
| `eth_call` block overrides (4th param, keys `time`, `timestamp`, `number`) | **Rejected**: `-32602 Invalid params` |
| `debug_traceCall` `blockOverrides` in options | **Silently ignored**: `Multicall3.getCurrentBlockTimestamp()` / `getBlockNumber()` returned the real chain values |

Consequence: the "+1 block" re-sim for TIMESTAMP/NUMBER-dependent contracts cannot be done on the public RPC. Options: (a) local fork (anvil/reth) with the next block's timestamp set, (b) accept the bytecode-scan flag only and label it heuristic. Not tested here: whether a local fork can reproduce Monad semantics (PRD already lists this limit). Do not let the SDK send `blockOverrides` to Monad; it fails silently.

## `debug_traceBlockByNumber` / `ByHash`

- `diffMode` supported. Returns an array with one entry per transaction.
- Size for one mainnet block (14 to 30 txs): callTracer about 0.33 to 0.6 MB, non-diff prestate **4 to 7.5 MB**, diffMode **0.22 to 0.35 MB**. Prefer diffMode for the "who wrote slot X" Explain step (writer attribution), and non-diff only for single txs.
- Latency: 0.13 to 2.7 s per block on mainnet public nodes, 1 request each; a 9.5 s outlier on testnet QuickNode for callTracer, and one 25 s timeout for non-diff prestate there.
- Works at `-100k` blocks on archive nodes; fails with the state-pruned error beyond the window elsewhere.
- Heavy, rate-limited: a burst after one trace hit HTTP 429 on `rpc.monad.xyz`. Do not fan out.

| Endpoint | Failed of 40 |
|---|---|
| rpc.monad.xyz | 0 (but `debug_traceBlock` repeated quickly returned 429 in a manual check) |
| rpc2.monad.xyz | 0 |
| rpc3.monad.xyz | 0 |
| testnet-rpc.monad.xyz | 0 |
| rpc1.monad.xyz | 4 (HTTP 429, HTML body) |
| rpc-mainnet.monadinfra.com | about 19 to 40 (HTTP 429 `Rate limit exceeded`, or connection reset) |
| rpc-testnet.monadinfra.com | about 19 to 26 (HTTP 429) |

The documented limits are 25 rps for QuickNode mainnet, 15 rps Alchemy, 20 rps Monad Foundation (hotslot `docs/chain.md`). The script's retry backs off 1.5 s x attempt on 429.

## Recommended RPC strategy

- **Live gate (simulate at `latest`, p50 matters):** `rpc.monad.xyz` primary (best p50 and p95 for debug_traceCall), `rpc2.monad.xyz` then `rpc-mainnet.monadinfra.com` as failover. 20 to 25 rps cap per IP, so cache per (to, selector, state block) and keep a hard timeout (about 2 s) with failover. Production: bring your own key or node; the public rps will not carry an unattended fleet. `rpc1` and `rpc3` give `eth_call` only, so use them just for plain reads (balance, nonce, receipts), never the trace.
- **Historical replay / K2 benchmark (blocks older than about 1.5M):** `rpc2.monad.xyz` (Goldsky) primary, `rpc-mainnet.monadinfra.com` secondary; both are full archive with tracing. Throttle to under about 10 rps with retries; use `debug_traceBlockByNumber` + `diffMode:true` for writer attribution, `debug_traceCall` non-diff at `N-k` for the read set. The 30-day window is about 6.5M blocks, so it needs the archive pair, not `rpc.monad.xyz`.
- **Testnet demo (mock market):** `testnet-rpc.monad.xyz` (about 64 days of state, tracing OK).
- **Receipt diffing ("why did it fail"):** must happen inside the window of the endpoint used; store the dependency receipt with its block hash so replay on an archive node stays possible.
- Paid keys (Alchemy PAYG, Dwellir, QuickNode archive) were not available; they would remove the rps risk but are not required for K1.
